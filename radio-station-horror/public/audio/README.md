# Audio drop folder

Everything here is optional. Missing files are skipped and never crash a render.

Sound effects: `<name>.wav` (or `.mp3` / `.ogg` / `.m4a`)

- low_ambient_hum, radio_static, three_beeps (3 beeps, 0.8 s apart), knocking (3 knocks, 0.55 s apart)
- breathing, electrical_buzz, impact, glass_break, motel_ambience
- optional extras: scratching, creak, whisper, phone_buzz, tv_on, train

Voice:

- `narrator.wav`: one continuous narration track, starting at the cold open (0:04.6)
- `narration/<chapterId>.wav`: one file per chapter
- `voice/<chapterId>/<beatId>.wav`: one file per line (run `npm run script:export` for the list)

`placeholders/` is generated by `scripts/prepare-assets.mjs`. Real files in this folder take priority over it.
