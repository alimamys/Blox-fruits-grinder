# Frame 240

A semi-realistic 2D animated horror short (about 10 minutes, 1920×1080, 24 fps). It is built with **Remotion + React + TypeScript** on the engine of "The 63rd Passenger".

A freelance animator finds an extra frame in her animation, with a man standing in her hallway. Every time she presses play, he is closer.

> Everything in this video is fictional.

- **Composition:** `Frame240Horror` is the YouTube cut. `Frame240HorrorFull` uses every line at its written pacing.
- **Story:** 11 scenes and 192 voice lines. Mara narrates her own story, and the same Fish voice speaks her on-screen lines. Hana is voice only, on the phone.
- **Picture:** every shot is first a code-drawn layout, then a frame generated by gpt-image-2 in the style of `references/style/animated2d.png`. Screens (the editor, the phone, `REC`, the selection and the cursor) stay crisp code.
- **Timing:** every cut, sound cue and ambience ramp is computed from the real WAV durations.

Production plan and status: [`PLAN.md`](PLAN.md), [`STATUS.md`](STATUS.md). The source script is in [`SCRIPT.md`](SCRIPT.md).

```bash

```

```bash

```

## How it fits together

```
src/
  Frame240Horror.tsx         places every scene, subtitles and the audio layer
  data/
    voiceLines.ts            every line: id, character, text, emotion, pace, pauses, effect, Fish tags
    voiceConfig.ts           casting: narrator + mara share one Fish voice; hana
    timeline.ts              scenes as ordered lines and silent beats; SFX cues; ambience beds; HITS
    edit.ts                  the short edit: cuts, pause caps, beat lengths
    art.ts                   art direction type for every shot (kind, prompt, characters, location, mood, fx)
  scenes/                    one module per sequence; every shot has a stable id, a layout and its art
  layout/                    LAYOUT GUIDES only: Mara mannequin, the tall figure, hallway, workroom, closet,
                             exterior, inserts; canvas pictures (pictures.tsx)
  components/ui/             crisp final UI: animation editor, phone screens, REC HUD, marching ants, cursor
  components/fx/Restyled.tsx generated frames as a motion comic: push and drift, keyframe crossfades,
                             mouth swap with the voice envelope, parallax, flicker/shake/tremble/glitch
  audio/AudioLayer.tsx       voices, SFX and beds (ducked under speech)
```

A shot looks like this:

```tsx
{
	id: 'cl_17_turn',                       // stable: names the generated files
	at: 'narrator_052_turned_around',       // cuts on this voice line
	render: ({f, d}) => <FrontMara ... />,  // the code layout (guide for the image model)
	art: {kind: 'action', keys: 3, chars: ['mara'], loc: 'workroom', mood: ..., prompt: 'Keyframe 1 ... 2 ... 3 ...'},
}
```

- `kind: 'reuse'` shows another shot's generated frame with a new move or effect, at no cost.
- `overlay` draws crisp moving elements over the generated frame: the pencil line, the marching ants, the cursor, the `REC` timer.

## Picture pipeline (`STYLE=semi2d`)

```bash
node scripts/images/refs.mjs           # layout guides for the canvas pictures and locations -> build/refs
node scripts/images/shotmap.mjs        # every shot with id, frames and art -> build/shotmap.json
node scripts/images/keyframes.mjs      # clean layout keyframes (fixed camera, mouths closed) -> build/keyframes
node scripts/images/mouthkeys.mjs      # mouth position of each talking frame
.venv/bin/python scripts/images/restyle.py lookdev     # character sheets + location references
.venv/bin/python scripts/images/restyle.py plan
.venv/bin/python scripts/images/restyle.py pictures    # pictures on Mara's screen, each an edit of one base frame
.venv/bin/python scripts/images/restyle.py gen --workers 4
MOUTH_VARIANTS=1 .venv/bin/python scripts/images/restyle.py mouths
.venv/bin/python scripts/images/restyle.py manifest    # -> src/data/generated/restyle.json + pictures.json
.venv/bin/python scripts/images/restyle.py cost        # what has been spent
```

- **What each request contains:** the layout keyframe (composition, poses, positions and props only), the character sheets of everyone in the shot, the location reference(s), and the style reference. The prompt names each image by its position, and adds the frame description, the scene's colour mood and the hard rules: five fingers, people sit on seats, no invented people or text.
- **Mouth variants:** an edit of the finished frame where only the mouth opens. Only the changed mouth region is merged back, so nothing else flickers while she talks.
- **Cost control:** every call's token usage goes to `logs/image_costs.jsonl`. A run stops before the estimated spend passes `IMAGE_BUDGET_USD` (default 50). Identical inputs are cached and never paid for twice.

## Voices

**Fish Audio Drama 3:** `FISH_MODEL=drama-3`, with the key read from `FISH_API_KEY`.

- **Casting:** `scripts/voice/fish_cast.py` auditions generic library voices only, with no celebrity or film-character clones.
- **Emotion:** each line carries a bracket tag such as `[whispering, scared]`, set per line by `fishTags` in `voiceLines.ts`.
- **After generation:**
  - `qa_voices.py`: Whisper QA; flagged lines are re-rolled best-of-3;
  - `tighten.py`: pacing;
  - `retime.mjs`: real durations into the timeline;
  - `speech_timing.py`: word timings for the subtitles and the mouth envelope.

The full commands are in `STATUS.md`.

## Sound

`scripts/sfx/build_real_sfx.py` builds every effect and ambience bed from real CC0 and CC-BY recordings (FSD50K, bank-sfx).

- **Beds:** computer fan, rain on the window, apartment tone, light buzz, closet tone, plus the low drone and the string pulse.
- **One-shots:** pencil scratches, clicks, taps, the wet peel and impacts.

CC-BY credits are listed in `public/audio/sfx/CREDITS.md` and in the YouTube description. Silence is part of the design: the beds drop out completely on the big beats.

## Switches (input props)

| prop | default | effect |
| --- | --- | --- |
| `restyled` | `true` | `false` shows the code layouts instead of the generated frames |
| `subtitles` | `true` | burned-in, word-timed subtitles with speaker tags |
| `grain` | `true` | film grain + vignette |
| `audio` | `true` | mute everything |
| `edit` | `'short'` | `'full'` for every line at its written pacing |
