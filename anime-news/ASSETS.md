## What is temporary right now

No image-generation tool is connected to this environment (no MCP tool, no API key) and Hugging Face / GitHub-release downloads are blocked by the network policy. So the preview uses:

- **TEMPORARY placeholder art** — anime-style animated plates drawn in code (`src/components/placeholders.tsx`, `src/components/anime/`), labelled `PLACEHOLDER ART · Axx` on screen. They set the look, timing and motion, but are stand-ins for the finished illustrations.
- **AI narration (Kokoro-82M, open weights)** — neural TTS generated offline in `public/audio/narration_tts/` (voice `bm_george`; switch with `--voice`). Far more natural than the first scratch voice, but still synthetic: replace with a human narrator or a premium voice service for the final.
- **TEMPORARY procedural score and SFX** — synthesised in code by `scripts/make_sfx.py` into `public/audio/sfx_temp/` (tension pad, accents, whooshes, riser, title hit, ambiences). Original, but meant to be replaced by designed/licensed sound.

## 1. Artwork

Format: 2560x1440 PNG (16:9) or larger, same aspect ratio. Layer files must use the same canvas size and alignment as the flattened file.

**Prepend this master style prompt to every artwork prompt:**

```text
Original cinematic retro 1980s/1990s political-thriller anime illustration; angular anatomy; strong ink contours; precise hard cel-shadow shapes; painterly location background; muted navy and charcoal base; rust-orange and amber rim light; subtle film texture; dramatic but restrained facial expression; clear visual hierarchy; 16:9 composition; generous crop room; no baked-in text, captions, numbers, channel logos, signatures or watermarks. Keep the same proportions, palette and line weight across shots. Illustrative editorial staging, not photographic evidence.
```

The **composition** line matters: the camera crops in code target those positions (stored as `anchors` in `src/data/assets.json` — adjust the numbers there if the delivered art is composed differently).

Portraits of real public figures (A03, A05): many image generators refuse or restrict recognisable likenesses. Use an illustrator or a tool whose terms allow neutral editorial depictions of public figures; keep them silent and neutral, as the brief requires.
